# VPK

VPK is a lightweight package manager for Vast Linux, written in Rust.

## Features
- Install and remove packages
- Search the package repository
- Verify package checksums
- Track installed packages
- Upgrade packages with confirmation
- Roll back failed upgrades

## Status
- VPK is still under development and could potentially have bugs :)

## Build

```sh
cargo build --release
```

## Usage

```bash
vpk --help
```
